# CamApp

Independent NeoCam source module, initially copied from NeoLab firmware.
See `neocam_csw/_metadata/source-mapping.json` for provenance.

Keep implementation, public contracts, module.cmake and owned tests here.
Product values and build configuration are supplied by neocam_csw/Conf.
Use the integration host-test runner after fetching dependencies.
To test uncommitted changes, bind this checkout with packages.local.yml.
CamApp is NeoCam-specific; its ASW/ASV/DE hierarchy is retained.
